# 0001-deployment-target-and-pwa

We decided to deploy the Next.js application to **Vercel** and configure it as a **Progressive Web App (PWA)** for cross-device support (iOS, iPadOS, macOS, Windows).

Vercel provides native Next.js Serverless runtime, zero-configuration HTTPS (mandatory for iOS Safari audio and microphone permissions), and secure server-side environment variables for the Gemini API key. PWA configuration enables "Add to Home Screen" on iOS/iPadOS Safari, delivering a full-screen, app-like experience without App Store submission overhead.
