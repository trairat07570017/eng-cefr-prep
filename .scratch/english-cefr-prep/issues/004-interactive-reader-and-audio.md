# Ticket 004: Interactive Daily Reader and Web Speech Audio

## Description
Develop the Interactive Reader screen featuring word tokenization, instant click-to-lookup tooltips, and Web Speech API audio narration with speed controls.

## Blockers
- 002-app-shell-and-sidebar.md
- 003-gemini-news-pipeline.md

## Acceptance Criteria
- [ ] Article displayed with clean typography and selectable word tokens.
- [ ] Clicking/tapping any word shows an instant popover with definition, part of speech, and "Save to Vocab Bank" button.
- [ ] Web Speech API audio player with Play / Pause / Reset and speed options (0.8x, 1.0x, 1.2x).
- [ ] Highlight sentences or words during playback.
- [ ] Tested for smooth interaction on iOS Safari touch events.
